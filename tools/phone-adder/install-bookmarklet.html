Add to Budget Basket

Chrome on Android cannot run extensions, so this is the same thing as a bookmark. Set it up once.

  1. Press Copy below.
  2. In Chrome, bookmark any page (menu ⋮ → ☆). Then menu ⋮ → Bookmarks → press and hold the new bookmark → Edit.
  3. Name it Add to app. Replace the address (URL) with what you copied (paste), and save.

If pasting says nothing happened, long-press the box below, Select all, Copy.

Using it

  1. On a store website, open the product (or a search page that shows prices).
  2. Tap the address bar, type Add to app and tap the bookmark in the suggestions.
  3. A box appears with what it found. Tap Save file for the app.
  4. In Budget Basket: More → Add items from a file, pick the file from Downloads.

Items already in the app are never added twice, and nothing in the app is replaced or removed.
